# 📦 Warehouse Management System (WMS)

A modern Warehouse Management System (WMS) built using **ASP.NET MVC** that helps manage products, inventory, suppliers, and warehouse operations through a clean and responsive web interface.

> 🚧 This project is currently under development.

---

## ✨ Features

### Current Features
- 📋 Product Management
- 🔍 Product Search
- ➕ Add Product
- ✏️ Edit Product
- 🗑️ Delete Product
- 📊 Responsive Product Table
- 🎨 Modern Dashboard UI

### Planned Features
- 📦 Inventory Management
- 📥 Stock In

- 🏷️ Categories
- 🚚 Supplier Management

## 🚀 Getting Started

### Prerequisites

- Visual Studio 2022 (or newer)
- .NET SDK
- SQL Server
- Git

### Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/WarehouseManagementSystem.git
```

2. Open the solution in Visual Studio.

3. Restore NuGet packages.

4. Configure the connection string in `appsettings.json`.

5. Run database migrations (if applicable).

6. Start the application.
